Methodology

Scored items use deterministic asserts (or hidden unit tests on Score). Exploratory items are side-by-side judgment only. There is no blended “best model” score across Fun, Dev, and Score.

The GitHub README omits some Dev paste so a casual chat session does not quietly contaminate a CLI matrix. Prompts are still public in the repo and in this explorer. Official fair runs: fork the repo, set your key, run npm run eval:fun / eval:dev / eval:score.

Score hidden tests are not published here. Clone GitHub to grade generated functions.
