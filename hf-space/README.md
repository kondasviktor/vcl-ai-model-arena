# VCL VibeBench

**Stop trusting benchmark slides. Run it yourself.**

Practical, reproducible AI model comparisons for developers, makers, indie hackers, and AI enthusiasts — by [Vibe Coder's Life](https://vibecoderslife.com/vibebench?utm_source=huggingface&utm_medium=space&utm_campaign=vibebench).

## What you can do here

- Browse Fun, Dev, and Score prompts
- Inspect the latest maintainer results (not a blended “best model” IQ score)
- Copy a prompt into any chat UI
- Fork the GitHub CLI for a fair BYOK multi-model run

This Space does **not** run models on Hugging Face compute. Official scoring is clone-and-run on GitHub.
