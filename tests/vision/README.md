# Vibe Vision fixtures (draft / unreleased)

Neutral motion cases for `npm run eval:vision`. Regenerate with:

```bash
npm run vision:export -- --word OCEAN --out tests/vision/cases/ocean
npm run vision:export -- --word RIVER --decoy BRIDGE --out tests/vision/cases/decoy-river
```

Do not treat this suite as a public 1.1 release until the VCL live demo is go-live approved.
